# College_Football_Transfer_Portal_analysis_RCode
Code used to analyze and illustrate FBS Transfer Portal activity for the 2023-2024 year.

Data came from [collegefootballreference](https://collegefootballdata.com/), [CFB Reference](https://www.sports-reference.com/cfb/) and [Pro Football Focus](https://www.pff.com/) (subscripion required)
The purpose was to do a general analysis of the transfer portal in college football, specifically quantifying the number of players who left and measuring the 'type' of player (good, bad, underplayed). The analysis was then used to write an article for MWC Connection, which can be read [here](https://www.mwcconnection.com/2025/7/2/24441085/college-football-transfer-portal-2025-mountain-west-conference-review-data-analysis)
